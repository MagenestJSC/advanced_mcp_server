FAQ

Frequently asked questions

Is Odoo MCP Server an AI chatbot inside Odoo?

No. Odoo MCP Server is a connection layer between Odoo and AI Agents through MCP. Users interact with AI on platforms such as Claude or Codex, while MCP Server allows AI to access and perform tasks in Odoo based on granted permissions.

Does the AI Agent get full access to Odoo after connection?

No. AI can only perform actions allowed by both the MCP module-level permissions and the permissions of the user account in Odoo.

Can AI be limited to read-only access?

Yes. Read, Write, Create and Delete permissions can be configured separately for each module. Enable only Read if you want AI to support data lookup without changing the system.

How should businesses start implementing it?

Begin with low-risk use cases and clearly defined permission scopes, such as read-only access. Once the process is stable, consider expanding to Create or Write permissions.

Which Odoo versions does it support?

Odoo MCP Server currently supports Odoo 19, making it easier to integrate AI Agents with multiple Odoo versions currently in use.
